# Icon source

`thunderphone.svg` and `thunderphone.dark.svg` use the sanctioned `TpBolt` vector from
`landing/src/components/handoff/parts.jsx`. `thunderphone.png` is a package-sized copy of
`web/public/logo-mark-volt.png`; its longest edge is 256 pixels and its aspect ratio is unchanged.

Do not draw a new logo, trace the mark, or replace it with a generic bolt icon. If the source asset
changes, regenerate this copy from the sanctioned repository asset and rerun the n8n linter and
build.

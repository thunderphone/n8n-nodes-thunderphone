# Icon source

`thunderphone.svg`, `thunderphone.dark.svg` and `thunderphone.png` are package-sized copies of
ThunderPhone's official thunderbolt-only brand mark, exported from the sanctioned source asset
without redrawing. The PNG's longest edge is 256 pixels and its aspect ratio is unchanged.

Do not draw a new logo, trace the mark, or replace it with a generic bolt icon. If the brand asset
changes, regenerate these copies from the official asset and rerun the n8n linter and build.
